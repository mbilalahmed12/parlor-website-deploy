## 🆘 Troubleshooting

### Issue: "404 Not Found" on website
**Solution:**
- Verify index.html is in the root of public_html/
- Clear browser cache (Ctrl+Shift+R)
- Wait 5-10 minutes for DNS

### Issue: Styling/CSS not loading
**Solution:**
- Verify _next/ folder uploaded completely
- Hard refresh browser (Ctrl+Shift+R)
- Check browser console for any errors

### Issue: Images/Videos not showing
**Solution:**
- Verify all files uploaded successfully
- Check that file paths are relative
- Verify media URLs in the HTML

### Issue: Domain not pointing to website
**Solution:**
- Complete domain registration in hPanel
- Check domain DNS settings
- Verify A record points to hosting IP
